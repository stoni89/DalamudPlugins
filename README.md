# Stoni's Dalamud Plugins

Custom plugin repository for Dalamud. Add this URL under
`/xlsettings` → Experimental → Custom Plugin Repositories:

```
https://raw.githubusercontent.com/stoni89/DalamudPlugins/main/repo.json
```

## Plugins

- [The Explorer's Codex](https://github.com/stoni89/explorers-codex)

`repo.json` is updated automatically by each plugin's release workflow.
